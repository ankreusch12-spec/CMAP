Importar

1. Forecast oficial (MOP)

Envie o FORECAST OFICIAL - OUTBOUND. O controle lê a aba BASE (MOP, Home, Staff e a carga 6H20/7H12 de cada frente), substitui o forecast anterior e mostra em O que subir a diferença para o que está no CMAP.

2. Relatório do CMAP (o que já está lançado)

Envie o Excel exportado do CMAP (o mesmo que alimenta a aba 12 month forecast) ou um arquivo gerado por Exportar Excel deste controle.

Colunas esperadas: Country · Location ID · Site ID · Site · Client · Project ID · Project · Dept · Shift · Eff Date · Qty

  • Só entram os locais que você acompanha (São Paulo BF4 e Barueri, Curitiba JL1/JL2/JL3/MAL2/MAL3, Ponta Grossa e WAH Brasil Direto WFH). Linhas de outros locais e de outros países são ignoradas. Para mudar a lista, use a coluna “Acompanho” em Locais.
  • Reservas são reconhecidas por Project ID + Location ID; as quantidades do arquivo substituem as atuais.

🔒 Os arquivos são lidos e descartados: só os números ficam no banco local do seu PC.
